📖 Cách Tải Code Lên GitHub & Phát Hành Bản Cập Nhật

            

              Để đưa dự án lên GitHub và phát hành bản cập nhật cho người dùng khác, bạn chỉ cần thực hiện 3 bước đơn giản:
            

            
    
              
  1. Kho GitHub chính thức: Được lưu trữ tại https://github.com/hotrocvst-cell/xmusic-station.
    2. 
              
  2. Đẩy code từ máy tính lên: Chạy git add ., git commit -m "v2.2.0", git push origin main.
    3. 
              
  3. Khi có bản cập nhật mới: Sửa số phiên bản trong file version.json và push lên GitHub. Mọi người dùng dùng XMusicStation bấm Kiểm tra cập nhật sẽ thấy bản mới và nạp bài hát trong 1-click!
    4. 
            

          

        


        
        

          

            

              
Hướng Dẫn Cài Đặt & Sử Dụng

              
Hướng dẫn chi tiết từng bước để cài đặt Extension hoặc Tampermonkey Userscript trên máy tính.

            

          


          

            

              
Cách 1: Tiện ích mở rộng Chrome / Edge (Khuyên dùng)

              
Cài đặt Chrome Extension (Manifest V3)

              
    
                
  1. Mở trình duyệt Google Chrome hoặc Microsoft Edge.
    2. 
                
  2. Truy cập đường dẫn: chrome://extensions (hoặc edge://extensions).
    3. 
                
  3. Bật công tắc "Chế độ dành cho nhà phát triển" (Developer mode) ở góc trên cùng bên phải.
    4. 
                
  4. Bấm nút "Tải tiện ích đã giải nén" (Load unpacked).
    5. 
                
  5. Chọn thư mục extension (từ thư mục tải về hoặc giải nén từ file zip trên GitHub Releases).
    6. 
                
  6. Truy cập player.xmusicstation.com, tiện ích sẽ tự động hiện thanh công cụ nổi và quản lý danh sách phát!
    7. 
              

            


            

              
Cách 2: Tampermonkey Script (Nhanh nhất)

              
Cài đặt qua Tampermonkey / Violentmonkey

              
    
                
  1. Cài đặt tiện ích Tampermonkey trên trình duyệt (nếu chưa có).
    2. 
                
  2. Bấm vào liên kết cài đặt tự động: Cài đặt xmusic-auto-playlist.user.js (Tampermonkey sẽ tự nhận diện và hiện nút Cài đặt / Install).
    3. 
                
  3. Hoặc sao chép toàn bộ nội dung file userscript/xmusic-auto-playlist.user.js và dán vào script mới trong Tampermonkey -> Nhấn Ctrl + S để lưu.
    4. 
                
  4. Khi truy cập player.xmusicstation.com, script sẽ tự động chạy mượt mà trên mọi trình duyệt!
    5.
